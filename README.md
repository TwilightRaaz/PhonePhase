# PhonePhase - Deep OSINT Phone Number Extractor (Liberty Edition)

An advanced Python script for deep information extraction and OSINT (Open Source Intelligence) reconnaissance.

## 🌟 Advanced Features
- **Basic Info:** Validation, formatting (International, National, E164), and number type identification.
- **Provider & Location:** Geographic region, carrier, and timezones.
- **Social Media Footprinting:** Direct links to WhatsApp, Telegram, Viber, and Skype.
- **AI Scammer Profiling:** Automated risk scoring based on number type (VOIP/Premium) and carrier reputation.
- **Data Breach Recon:** Automated search links for DeHashed, IntelligenceX, and Snusbase to find leaked passwords and names.
- **Ad Fingerprinting:** Deep dorks for Craigslist, eBay, and social platforms to find linked listings.

## 🛠️ Installation

1. Ensure you have Python 3 installed.
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

python3 phonePhase.py +14155552671
